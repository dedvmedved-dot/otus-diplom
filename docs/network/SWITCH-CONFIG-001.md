## 3. Конфигурация коммутатора — bond0


### LAG/bond

```text
Тип: LACP (802.3ad) — предпочтительно
Fallback: режим active-backup на серверах (если LACP невозможен)

Порты каждого сервера должны быть в ОДНОМ LAG.
Если используется MLAG/MC-LAG/VPC/stack между двумя коммутаторами:
  — ОДИН логический LACP peer на сервер
  — port-channel/LAG с两台 коммутаторов
```

## 6. Серверная конфигурация (что настроит Hermes после switch-side)

```text
bond0:
  mode: 802.3ad | active-backup
  slaves: ens2f0 + ens2f1
  VLAN: 700, 140, 143

bond1:
  mode: 802.3ad | active-backup
  slaves: ens2f2 + ens2f3
  VLAN: 141

На всех трёх узлах идентично.
```
