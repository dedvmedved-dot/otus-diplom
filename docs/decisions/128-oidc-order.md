# Наряд по #128: один ручной диагностический запуск OIDC

Исполнитель: `hermes-5.187.1.37-engineer`. Основание: [разрешение владельца](https://git.aiopslab.online/aiopslab/otus-diplom/issues/124#issuecomment-9906) и [подтверждение пары](https://git.aiopslab.online/aiopslab/otus-diplom/issues/127#issuecomment-10410). Это единственный наряд на запуск в продолжение #126, не дополнительная попытка.

1. Перед dispatch проверь историю запусков и отсутствие параллельной заявки, доступность доверенного runner `otus-diplom` и неизменность цели в `aiopslab/otus-diplom`: `.forgejo/workflows/oidc-diagnostic.yml`, `refs/heads/engineer/126-oidc-pilot`, SHA `95f6cb271b2da4053b157c81317c46641ac556d0`. Если попытка уже была — только отчёт по ней. Если историю, цель или изоляцию подтвердить нельзя — `BLOCKED`, без dispatch.
2. Только при успешной проверке выполни один `workflow_dispatch` этого workflow на указанном ref. Не меняй ветку или workflow. Ошибка тоже расходует попытку; при тайм-ауте или неоднозначном ответе только проверь историю, запрос не повторяй. Никаких rerun. Не запускай `p8c-portal-forgejo-release`; запрещены build/push/sign/attest, обновление lock и публикация.
3. Верни архитектору в задаче ссылку на run, run ID, статус, фактические workflow/ref и SHA. Из токена приведи только наблюдённые `iss`, `aud`, `sub`. Не выводи JWT, полный payload, заголовки авторизации или секреты в лог, артефакт или задачу; не прикладывай дампы. При сбое отметь, что именно не получено, и безопасную причину. Если run не создан, не подставляй run ID или claims.
4. После отчёта остановись. Если claims не получены или изоляция невозможна — `BLOCKED`, запрос подтверждения identity у оператора CA без нового dispatch. При успехе архитектор проверяет свидетельство именно этой пары; диагностический `sub` не подтверждает identity выпуска или SAN. Выпускной плейсхолдер не менять до отдельного решения по привязке workflow/ref к SAN, политике CA, trust roots и эксклюзивному admission-барьеру (#111). B остаётся `NOT_READY_FOR_DISPATCH`; digest/provenance — `NOT_VERIFIED`.
