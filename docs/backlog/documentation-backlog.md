# Documentation Backlog

Non-critical, cosmetic/editorial documentation issues deferred per the
Documentation 3/3 rule. Technical documentation defects (wrong command, IP,
disk ID, restore/DRBD procedure, invalid manifest, false evidence, wrong
RPO/RTO, non-reproducibility) do **not** belong here — they are fixed
immediately regardless of the counter.
