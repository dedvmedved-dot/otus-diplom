# TASK-P7A — Velero Kubernetes 1.36 Risk Classification

Source: velero-io/velero README (main) compatibility matrix.

| Velero version | Expected Kubernetes compatibility | Tested on Kubernetes |
| 1.18           | 1.18-latest                      | 1.33.7, 1.34.1, 1.35.0 |
| 1.17           | 1.18-latest                      | 1.31.7, 1.32.3, 1.33.1, 1.34.0 |

Velero v1.18.1 release body: "Bump external-snapshotter to v8.4.0 and migrate
VolumeGroupSnapshot API from v1beta1 to v1beta2 for Kubernetes 1.34+ compatibility".

Classification for this cluster (Kubernetes 1.36.2):
  VELERO_EXPECTED_COMPATIBILITY_WITH_K8S_1_36 = TRUE
    (Velero 1.18 expected compatibility = "1.18-latest", which includes 1.36)
  VELERO_UPSTREAM_TESTED_ON_K8S_1_36 = FALSE
    (upstream test matrix stops at 1.35.0; 1.36 not listed)
  VELERO_K8S_1_36_RISK = EXPECTED_COMPATIBLE_BUT_NOT_UPSTREAM_TESTED

Conclusion: a later runtime canary is mandatory before production Velero use on 1.36.2.
